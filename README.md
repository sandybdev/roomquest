# ROOM QUEST

실제 공간 제약을 반영한 브라우저 기반 3D 인테리어 퍼즐 게임.

## 플레이
https://sandybdev.github.io/roomquest/

## 현재 구현 (Alpha)
- 문제 출제 / 문제 풀이 분리
- 방 크기, 문, 콘센트, 벽지, 예산, 필수/허용 가구
- Three.js 기반 3D 배치 및 카메라
- 가구 충돌, 기본 개폐 여유, 전원 케이블 거리, 멀티탭 연결, 예산 검사
- 브라우저 localStorage에 문제와 작품 저장
- 로컬 작품 갤러리 및 좋아요

## 중요한 제한
- 브라우저 localStorage는 다른 사용자와 공유되지 않습니다.
- 충돌/개폐 검사는 현재 단순화된 직사각형 근사입니다.
- 전선 경로, 실제 전기 안전, 실제 동선은 정밀 검증되지 않습니다.
- 가구는 임시 3D 형상이며 오늘의집 상품 데이터가 아닙니다.
- 계정, 서버 저장, 공개 갤러리/랭킹, 악용 방지 및 운영 기능은 아직 없습니다.
